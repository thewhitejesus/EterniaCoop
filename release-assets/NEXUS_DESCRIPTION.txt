Eternia Co-op

Play battles with up to 4 players, like the PS1 original. Each controller controls its own party member.

INSTALL
1. Open the game folder: Steam > right-click Tales of Eternia Remastered > Manage > Browse local files.
2. Extract the zip into that folder (BepInEx is included).
3. Steam Deck / Linux: in the game's Steam Properties > Launch Options, enter WINEDLLOVERRIDES="winhttp=n,b" %command%
4. Start the game. You'll see "Eternia Co-op" in the top-right of the title screen.

HOW TO PLAY
- Plug in controllers. Player 2 gets the 2nd character, player 3 the 3rd, and so on.
- Players 2-4 control their character in battle. Menus and the field stay with player 1, like the PS1.
- Press F1 (or hold L3 + R3 on a controller) to choose who is which player.
- To let the AI play a character again, set it to Auto in the Skills menu.
- Playing online? Use Parsec. Only the host needs the mod.

FEATURES
- Up to 4 players in battle
- Automatic controller setup, join or leave mid-battle
- Controller manager (F1 / L3 + R3)
- Semi-Auto / Auto tab for every character
- Each player's controller rumbles for their own character

SAFE TO USE
- No internet access, tracking or telemetry
- Doesn't change any game files. Delete it and the game is back to normal
- Works alongside other mods: it checks the game code first and skips only the parts another mod or a game update changed
- Open source on GitHub: https://github.com/thewhitejesus/EterniaCoop

KNOWN LIMITATIONS
- Tested with 2 players. 3-4 players and Parsec should work, feedback welcome!
- A controller shows up twice? Turn off Steam Input for the game.
- Works with 100% Drop and Steal Rate (the controller manager moves to F8) and Guests from Phantasia (the controller shortcut moves to LB + RB + Back; with 4 players, set ReplaceFourth=0 in ToE_Guest.ini). Not compatible with Uncropped Backgrounds (it needs BepInEx 6).

UNINSTALL
Delete winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt, EterniaCoop-README.md and the BepInEx folder.
